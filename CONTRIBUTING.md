# Contributing to Mobile Price Classification

Thank you for your interest in contributing! Whether you are collaborating on this project as part of a team or reviewing the code, please follow these guidelines:

1. **Fork & Clone:** Fork the repository and clone your local copy.
2. **Create a Branch:** Create a feature branch for your changes (`git checkout -b feature/AmazingFeature`).
3. **Commit Your Changes:** Commit your changes with descriptive commit messages (`git commit -m 'Add hyperparameter tuning for Gradient Boosting'`).
4. **Push to the Branch:** (`git push origin feature/AmazingFeature`)
5. **Open a Pull Request:** Submit a pull request detailing your updates and model evaluation changes.
